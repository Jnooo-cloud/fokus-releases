# Fokus

Website blocker and time tracker for macOS. Runs locally, no account, no browser extension. English and German, follows your Mac's language.

**Download:** [Latest version](https://github.com/Jnooo-cloud/fokus-releases/releases/latest) → `Fokus-<version>.dmg`

## Install

1. Open the DMG and drag Fokus into Applications.
2. Open Fokus. macOS blocks it the first time, close the warning with "Done".
3. System Settings → Privacy & Security → scroll down → next to "Fokus was blocked", click "Open Anyway".
4. The app walks you through the rest and tells you about updates on its own.

Requires macOS 15 or later. This repo only holds the finished builds.

---

**Deutsch:** DMG öffnen, Fokus in Programme ziehen, öffnen, Meldung mit „Fertig“ schließen, dann Systemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“. Den Rest erklärt die App.
