# Fokus

Website-Blocker und Zeit-Tracker für macOS. Lokal, ohne Konto, ohne Browser-Erweiterung.

**Download:** [Neueste Version](https://github.com/Jnooo-cloud/fokus-releases/releases/latest) → `Fokus-<version>.dmg`

## Installieren

1. DMG öffnen, Fokus in den Programme-Ordner ziehen.
2. Fokus öffnen. macOS blockt die App beim ersten Mal, Meldung mit „Fertig“ schließen.
3. Systemeinstellungen → Datenschutz & Sicherheit → ganz nach unten → bei „Fokus wurde blockiert“ auf „Dennoch öffnen“ klicken.
4. Den Rest erklärt die App selbst. Updates meldet sie automatisch.

Dieses Repo enthält nur die fertigen Versionen. Benötigt macOS 15 oder neuer.
